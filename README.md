# 🚨 DisasterAssist-AI

### AI-Powered Disaster Management & Decision Support System

DisasterAssist-AI is an AI-powered Disaster Management and Decision Support System designed to assist in effective disaster response, resource planning, and emergency decision-making.

The system uses data analysis and Machine Learning techniques to understand disaster situations, predict resource requirements, and support efficient allocation of limited emergency resources.

---

## 📌 Problem Statement

During natural and man-made disasters, emergency response teams often face challenges such as limited resources, delayed decision-making, uneven resource distribution, and lack of accurate information.

DisasterAssist-AI aims to address these challenges by providing a data-driven system that can assist authorities and response teams in predicting resource requirements and making better resource allocation decisions.

---

## 🎯 Objectives

- Predict the required resources for different disaster situations.
- Analyze historical and disaster-related data.
- Apply Machine Learning for resource requirement prediction.
- Compare different Machine Learning models.
- Support efficient allocation of limited emergency resources.
- Reduce resource shortages and unnecessary resource wastage.
- Provide data-driven decision support for disaster management.

## 🧠 Machine Learning

The project uses Machine Learning algorithms to predict disaster-related resource requirements.

### Models Used

- Decision Tree
- Random Forest
- XGBoost

The performance of the models is compared using suitable evaluation metrics. The best-performing model is selected for the final prediction and decision-support process.
